# Fitness App with AI Chatbot

A Flutter-based fitness mobile application developed collaboratively within a cross-functional team, focusing on clean architecture, scalability, and real-world integrations.

The application provides users with personalized fitness guidance through an AI-powered chatbot, along with secure authentication and a smooth user experience.

---

## 👥 Team Collaboration
This project was developed as part of a team environment where all members contributed across multiple parts of the application.  
We worked closely with:
- Business Analyst (BA) for requirements and user flows
- Backend developers for API design and integration

---

## 🛠️ Tech Stack
- Flutter & Dart
- State Management: Bloc / Cubit
- Architecture: Clean Architecture, MVVM/MVI
- Networking: REST APIs, Retrofit
- Firebase:
  - Analytics
  - Crashlytics
- CI/CD:
  - GitHub Actions
  - Automated build and deployment pipelines

---

## ✨ Features
- User authentication and profile management
- AI-powered chatbot for personalized workout and nutrition guidance
- Clean and maintainable architecture
- API integration with backend services
- Crash monitoring and analytics using Firebase
- Automated CI/CD pipeline for reliable builds

---

## 🔄 Development Practices
- Agile team workflow
- Code reviews and collaborative development
- Continuous Integration & Continuous Deployment (CI/CD)
- Close collaboration with BA and backend teams
